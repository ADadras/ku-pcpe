# Frozen protocols and reproduction scope

Primary benchmark: positive image-label queries on the three-expert KU-PCPE test set. No negative queries are inferred. Each saved family has exactly 1,327 masks; missing masks raise errors. Multi-label images retain independent label targets. Split-local source names map to train_img or test_img separately.

SAM2.1 Hiera-L benchmark bank: checkpoint sam2.1_hiera_large.pt; config sam2.1_hiera_l.yaml; 32 points per side, 128 points per batch, predicted IoU .70, stability .92, stability offset .70, crop layers 1, box NMS .70, crop point downscale 2, minimum region area 25, mask-to-mask refinement. Original predicted-IoU/area ordering and maximum 128 masks are preserved. Mean unique-image bank size 54.48, task-weighted 53.77. Visible bank is exactly its original first 12; 67 tasks / 59 images have fewer. Annotation assistance used original SAM2 Hiera-L (sam2_hiera_large_072824.pt), not this benchmark bank. Historical annotation generation thresholds were not recorded in preserved caches; current defaults must not be represented as historical settings.

Template selector: average training masks at 192-square using OpenCV INTER_AREA, median training area threshold, bilinear heatmap resize. Candidate score .7 learned-template IoU + .3 geometric-template IoU, highest three with stable original-index ties. Greedy oracle forces min(3,n) additions, even when an addition decreases Dice. Integer bitsets accelerate exactly the same discrete objective. Exact-on-12 enumerates all subsets of exactly min(3,n), or at most three including empty, maximizing Dice. It is not a deployable selector, and non-Dice metrics are not independently optimized ceilings.

Dice/IoU: both empty -> 1; overcoverage outside-target pixels divided by predicted area, empty prediction -> 0. Hit uses Dice >= .5. Canonical B-F1: binary prediction and target resized only if long side >256 using Pillow bilinear and threshold >=128, erosion boundary, Euclidean tolerance <=2. Human LOO uses OpenCV nearest resize. Descriptive pairwise agreement in the paper uses transition boundaries and a separate jointly aligned orientation analysis. These historical conventions are disclosed, not silently standardized.

VLM prompt: The image contains numbered SAM2.1 candidate regions. Select up to three region IDs that best mark the visible evidence supporting the composition label "{label}". Return only a JSON list of integers.

Frozen checkpoint IDs: Qwen/Qwen3-VL-32B-Instruct; Qwen/Qwen3-VL-8B-Instruct; OpenGVLab/InternVL3_5-38B-Instruct; OpenGVLab/InternVL3_5-8B-Instruct; openbmb/MiniCPM-V-4_5; allenai/Molmo2-8B; llava-hf/llava-onevision-qwen2-7b-ov-hf. Original decoding is greedy, maximum 64 new tokens. Tier 1 reads preserved raw responses, takes the first bracketed substring if present, then the first three distinct valid integers. No accepted IDs -> empty prediction. It does not rerun these models or require their weights.

Supervised protocol: image-grouped 90/10 train/validation split, seed 13, 384-square input/mask, synchronized horizontal flip .5, U-Net 80 epochs / batch 24 / AdamW learning rate .0002; SegFormer 40 epochs / batch 10 / learning rate .00006; weight decay .0001 for both, BCE+soft Dice, highest validation Dice checkpoint, threshold .5. Image-only compact U-Net (base32, three encoder/decoder stages); label variant concatenates nine tiled channels. SegFormer-B0 encoder nvidia/segformer-b0-finetuned-ade-512-512 with 32-dimensional tiled label embedding and convolutional decoder. One fixed seed. Saved masks are supplied; no new training claim is made.

Auxiliary recognition: separate ImageNet ResNet-50; 85/15 train/validation, 224-square, color jitter/horizontal flips, binary cross-entropy, AdamW .0003, weight decay .0001, batch64, 12 epochs, best validation mAP. Grad-CAM uses final ResNet stage; DINO comparison uses vit_small_patch16_224.dino, patch/global cosine. Expert-area-matched and best-of-fixed-area sweep are target-dependent diagnostics. Blur/fill deletion uses the same classifier and is not a substitute for human region agreement. These optional inference pipelines are not implemented or claimed fully reproduced by the minimal Tier 1 package. Original detector triangle comparison is automatic KU-PCP detector output, not a human line target.

Main table mapping and exclusions are in README. The companion author research audit independently reproduced core results, human LOO, overlays, triangle and label-conditioning diagnostics. Those audits are distinct from clean-checkout Tier 1 results.


The original frozen bundle retains the earlier single-expert workflow labels. The updated paper uses the additional complete metadata archive: all four raters for process summaries, and the three experts jointly for a disjoint 615/712 test-task grouping. Retained events do not reconstruct discarded drafts or all later mask revisions, including the 71 symmetric replacements disclosed in the historical analysis. See `docs/COMPLETE_STUDY_METADATA.md` for exact definitions and commands.


Supervised preprocessing uses bilinear RGB resizing, nearest-neighbor mask resizing and RGB scaling to [0,1]. SegFormer additionally subtracts ImageNet mean [.485,.456,.406] and divides by standard deviation [.229,.224,.225]. U-Net does not apply that normalization. Saved full-resolution probabilities were linearly resized before the .5 threshold.
